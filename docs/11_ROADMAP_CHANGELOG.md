# Roadmap

What is coming next in the cave. Ideas, not promises -- the community votes.

## v0.2 -- More ways to play

- **Browser playground**: run CMC programs directly on the website, no install.
- **Block editor polish**: more blocks (`find`, `split`, `join`, `numba`),
  copy/paste between stacks, block right-click "wrap in repeat".
- **Picture saving**: save the Draw tab as a PNG.
- **Sound blocks**: simple beeps and tones.
- **Better terminal drawing**: draw without opening a window (ASCII mode).

## v0.3 -- Bigger projects

- **Imports**: put clumps in another file and `bring` them in.
- **Dictionaries**: piles with named spots (`player["name"]`).
- **More pile helpers**: `sort`, `shuffle`, `slice`.
- **Text slicing**: `word[2:5]`.
- **Step-through debugger**: run one line at a time and watch the boxes.

## v0.4 -- Growing up

- **More keywords in other languages**: Spanish, French, and more caveman
  grunts.
- **Compile to JavaScript**: CMC in the browser and beyond.
- **Hardware kits**: turn `skrib line` into real robot movement (Makey Makey,
  micro:bit, and friends).
- **Curriculum pack for classrooms**: lesson plans, printable workbooks,
  grading rubric.

## Someday

- A pocket CMC device with two buttons and a tiny screen.
- A CMC storybook where each page is a program.
- An official CMC mascot plushie. Ugg demands it.

## How to push an idea up the list

Open an issue on GitHub with the tag `idea` and say who it helps. Real stories
("my 5 year old wants to...") beat wishlists.

# Changelog

## v0.1.0 -- the first fire

The first release. Everything started here.

**The language**

- Caveman keywords: `oga`, `grunk`, `binga`, `wonga`, `unga`, `booga`, `zug`,
  `zoop`, `clump`, `ork`, `blorp`, `skrib`, `ugg`
- English aliases: `print`, `let`, `if`, `else`, `end`, `repeat`, `while`,
  `for`, `function`, `return`, `ask`, `draw`, `comment`, `true`, `false`,
  `nothing`
- Values: numbers (int/decimal), text, truth (`gronk`/`nork`), `plop`, piles
- Helpers: `snorf`, `plop`, `nom`, `skoop`, `yoink`, `goop`, `shout`,
  `whisper`, `flip`, `find`, `split`, `join`, `what`, `numba`, `munga`,
  `round`, `flat`, `roof`, `abs`, `small`, `big`, `root`, `pow`, `wait`
- Drawing: `skrib` circle, dot, line, box, blob, write, color, size, clear
- Friendly OOGA errors with line numbers and hints
- Loop step limit and recursion depth limit so programs never freeze a computer
- The magic `lap` box in `booga` loops

**The compiler**

- `cmc` command: REPL, `run`, `compile` (to Python), `init`, `examples`,
  `version`
- Python code generation with a small embedded runtime
- 123 tests covering the language, examples, code generation, blocks, and the
  IDE

**OGABOOGA CODER**

- Text tab with line numbers and CMC syntax colors
- Blocks tab: drag-and-drop palette, nesting, buttons, undo, error checking
- Draw tab with a 500x400 canvas
- Run/stop with a background thread, question windows for `blorp`, live output
- Examples browser and searchable caveman dictionary
- Export to Python

**Docs and site**

- 31 example programs with expected outputs
- A wiki with a page for every word
- Download page, main page, installation guide, 30-minute tutorial
- Publishing guide for GitHub and GitHub Pages
