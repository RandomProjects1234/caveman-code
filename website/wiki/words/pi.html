pi

Values

The circle number, about 3.14159.

How to write it

pi

What it does

pi is the magic number of circles. It is already there, ready to use.

Example

oga "A circle with radius 2 has around area", pi * 2 * 2

Tips

  • It is really 3.141592653589793 -- CMC remembers the rest.
