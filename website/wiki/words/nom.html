nom

Piles

How many things? (length of a pile or text)

How to write it

nom(<pile or text>)

What it does

nom counts. For a pile it counts the things. For text it counts the letters.

Example

grunk word = "cave"
oga nom(word)      ugg 4

grunk xs = snorf(1, 2, 3)
oga nom(xs)        ugg 3

Tips

  • Empty pile: nom is 0. Empty text "": nom is 0.
