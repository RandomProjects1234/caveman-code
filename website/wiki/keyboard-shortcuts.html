Running

KeyWhat it does
F5Run the program
EscStop a running program

Files

KeyWhat it does
Ctrl+NNew program
Ctrl+OOpen a .cmc file
Ctrl+SSave (asks for a name the first time)
Ctrl+ZUndo (in the Text tab, the editor's undo; in Blocks, the block undo)
Ctrl+YRedo in the Text tab

Editing text

KeyWhat it does
TabInsert four spaces
EnterNew line, keeping your indentation, plus four spaces after a block opener
Click a line number areaNothing yet -- line numbers are just for looking

Blocks

Key or mouseWhat it does
Click palette blockAdd it to the end of the stack
Drag palette blockDrop it exactly where you want
Click a slotType an expression
Drag a value block into a slotFill the slot with that value
Right-click blockDelete, Copy, Move up, Move down
Drag onto the paletteDelete the block
DeleteDelete the selected block
Ctrl+ZUndo
Click empty canvasDeselect

Dictionary and examples

Inside the dictionary: type in the search box to filter words. Inside the examples window: click a name to preview, double-click to open in the Text tab.

Terminal shortcuts

When using cmc in a terminal (not the IDE):

KeyWhat it does
Ctrl+CStop the running program
Ctrl+DLeave the REPL
Type quitLeave the REPL politely
