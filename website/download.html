Download Cave Man Code

CMC is free, tiny, and runs on Windows. The compiler and the IDE are built in C++ with no dependencies. Everything you need is in one zip: the compiler, OGABOOGA CODER, all examples, and the docs.

OGABOOGA CODER WEB

Nothing to download and nothing to install. The full IDE with the C++ compiler running in your browser.

How to install (Windows)

1. Download a zip above and right-click -> Extract All...
2. Open the extracted folder.
3. Double-click OGABOOGA CODER.exe  (or drag a .cmc file onto cmc.exe)

How to build from source

unzip CMC-Compiler-v0.1.0.zip
cd caveman-code
native\build.bat
cmc.exe run examples\01_hello_oga.cmc
OGABOOGA CODER.exe

Build your own programs (optional)

The zips already contain stand-alone cmc.exe and ogabooga.exe with no dependencies. To build them yourself with g++ or clang:

native\build.bat

System needed

  • Windows 10 or newer (the compiler and REPL also build on macOS/Linux)
  • No runtime to install -- the programs are self-contained
  • About 10 MB of space, no internet needed after download

A note about antivirus warnings

CMC is a small open-source project, and the programs are not code-signed yet. Antivirus tools (especially Windows Defender's machine-learning heuristic) can sometimes flag freshly built programs by mistake. If that happens to you, it is a false positive: the full C++ source is in the zip and in the repository, and you can check it yourself. You can help everyone by reporting the file to Microsoft as a false positive at the Microsoft file submission page. Thank you!
